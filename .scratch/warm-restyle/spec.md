# 暖纸换肤（warm-restyle）

Status: resolved（2026-10-11 实现于分支 feat/warm-restyle，tickets 01-03 全关闭）

> 来源：2026-10-11 grilling 两轮共识，用户逐题确认（含两轮"按照你的推荐"）。毛玻璃教训见 tasks/lessons.md 同日条目；迭代上下文见项目记忆 qink-ui-warm-restyle。

## Problem Statement

Qink 的界面是一张常驻桌面的便利贴，用户每天看它几十次，但当前配色（冷灰白底 + 墨黑文字 + 琥珀橙点缀）过于简约普通，没有记忆点，和用户的审美取向（个人网站的暖色复古印刷风）不一致。用户希望这张天天见的贴纸有"自己的样子"。

## Solution

把贴纸整体换成用户个人网站的配色语言：奶油米纸感底、墨橄榄文字、砖橙作为唯一强调色、卡其色 hover 反馈，纲领性文字（季/月/周目标）用衬线字体呈现"印刷品"气质。警示红（截止/逾期）与置顶紫两个状态色保持原样，确保一眼分得清"滚入/置顶/紧急"。不改动任何布局、尺寸和交互逻辑——只换皮肤，加少量同风格的点缀。

## User Stories

1. 作为 Qink 用户，我希望贴纸底色是温暖的奶油米色，这样它像一张真的纸贴在桌上，而不是一块冷灰的屏幕区域
2. 作为 Qink 用户，我希望标题和正文用深浅两档墨橄榄色，这样"把最重要的事天天被看见"有印刷品的层次感
3. 作为 Qink 用户，我希望季/月/周目标文本用衬线（宋体族）呈现，这样纲领文字有庄重的"刊物标题"气质
4. 作为 Qink 用户，我希望季/月/周小标签也是衬线小字，这样和目标文本形成同风格的排印组合
5. 作为 Qink 用户，我希望滚入的昨日任务显示为砖橙色，这样"从昨天滚进来的事"有暖色的延续感而非突兀的亮橙
6. 作为 Qink 用户，我希望任务行悬停时出现淡卡其底色，这样鼠标反馈是暖的、轻的，不破坏纸面
7. 作为 Qink 用户，我希望右上角收起按钮悬停时变砖橙，这样可点击处有品牌色的低声提示（修订：原稿提及的"⋯ 菜单按钮"在应用中不存在——菜单经右键唤出、无独立按钮，评审后修正）
8. 作为 Qink 用户，我希望右键抽屉菜单也是奶油/卡其体系，这样弹出的菜单不像从另一个应用里飞出来的
9. 作为 Qink 用户，我希望底部速记输入区和悬浮球的速记胶囊同为暖纸色，这样所有输入场合气质统一
10. 作为 Qink 用户，我希望收起后的悬浮球也是奶油米底 + 墨橄榄 Q，这样贴纸收起来品牌色依然在场
11. 作为 Qink 用户，我希望已完成任务的永久裂纹随新配色自动变暖，这样"碎过"的痕迹融进纸面而不是浮在上面
12. 作为 Qink 用户，我希望任务完成时碎裂的玻璃屑是橄榄墨色调，这样动画残影不脱离新色板
13. 作为 Qink 用户，我希望截止 24 小时内的任务仍然是醒目的纯红色，这样"快到期"的警讯不因换肤而减弱
14. 作为 Qink 用户，我希望逾期时悬浮球的裂缝仍然是纯红色，这样逾期的严重感与砖橙的日常感拉开距离
15. 作为 Qink 用户，我希望双击置顶的任务仍然是紫色，这样"我标记的"和"滚入的"两种高亮不会混
16. 作为 Qink 用户，我希望滚入（砖橙）、置顶（紫）、紧急（红）同时出现时仍按 红>紫>橙 的优先级显示，这样多状态叠加时不产生歧义
17. 作为 Qink 用户，我希望纸面的噪点颗粒质感保留，这样奶油底是真的"纸"而不是一块纯色
18. 作为 Qink 用户，我希望便签的阴影仍然是柔和的四档墨影（只是色相随文字变暖），这样贴纸依然"浮"在桌面上而不突兀
19. 作为 Qink 用户，我希望贴纸的尺寸、圆角、窗口边距、所有手势完全不变，这样换肤不打断我已形成的肌肉记忆
20. 作为维护者，我希望全部颜色改动收敛在 token 层完成，这样未来再调色只需动一处
21. 作为维护者，我希望强调色变量改名后名字与新色值一致（琥珀橙退役），这样后人不被撒谎的名字误导
22. 作为维护者，我希望本次不引入任何新测试缝和新逻辑分支，这样 62 项既有测试就是回归护栏

## Implementation Decisions

- **改动面**：全部颜色收敛于渲染层样式表的 `:root` token 层（现状：组件层无散落色值，改 token 即全局生效）；碎裂动画模块仅改色值常量。零逻辑变更、零几何变更（窗口透明边距、贴纸尺寸、手势阈值全部不动）。
- **色板映射**（现 token → 新值）：

| 用途 | 现值 | 新值 |
|---|---|---|
| 贴纸底 | `#fafaf8` | `#f0edda` 奶油米（截图实测） |
| 菜单底 | `#f5f5f3` | `#ebe7d1` 奶油加深一档 |
| 强文字（新增 token） | —— | `#3f4126` 墨橄榄深档（目标大字；截图值含抗锯齿偏浅，标题取深档保对比） |
| 正文文字 | `#1d1d1f` | `#4f5134` 墨橄榄（奶油底对比度 ~6.8:1，过 AA；淡字仍走透明度） |
| 主强调（`--amber` 改名 `--accent`） | `#d97706` | `#c96442` 砖橙 |
| 强调深（`--amber-ink` 改名 `--accent-ink`） | `#92400e` | `#8f3f24` |
| hover/选中底 | 墨色淡底 | 卡其 `#ded6b6` 低透明度（~30% 起调） |
| 细线/勾边/阴影四档 | `rgba(29,29,31,…)` | `rgba(63,65,38,…)` 同比例（浓度与四档结构不动，ADR-0008 框架内） |
| 置顶紫 | `#7c3aed` / `#5b21b6` | **不动** |
| 警示红 | `#dc2626` / `#991b1b` | **不动** |
| 噪点透明度 | `0.14` | **不动**（纸感来源） |

- **改名理由**：琥珀橙退役后 `--amber` 之名与 `#c96442` 之实相悖；消费面仅在渲染层样式表内，机械替换，无跨层引用。
- **字体**：新增衬线字体栈 token（宋体族：Songti SC / STSong / SimSun / Noto Serif SC 兜底，系统字体零打包）；应用于季/月/周目标文本（配深档墨橄榄）与季/月/周小标签。空态引导语、任务行、输入框、菜单、清单保持无衬线——操作区可读性优先。
- **语义色不动的理由**（grilling Q10 + 连带判定）：调暖红会与砖橙色相过近，造成"滚入还是逾期"的状态误读；置顶紫同理保辨识。红>紫>橙叠加优先级是既有规则，不受影响。
- **结构点缀**（grilling Q8 采纳项）：① 标签衬线小字（无色块）；② 任务行 hover 淡卡其；③ 收起钮/⋯钮 hover 砖橙；④ 速记输入区与胶囊微卡其底；⑤ 归档裂纹随 token 自动暖化。已砍"标签砖橙反白块"——砖橙只给交互反馈与滚入任务，避免三行标签全上橙块的喧闹。
- **碎裂动画**：玻璃屑与永久裂纹的墨色系常量随前景换橄榄墨同源色相，几何与时长零改动。

## Testing Decisions

- **好测试的标准**：只测外部可见行为。本迭代无新逻辑，因此**不新增测试、不新增测试缝**——理想缝数是零。
- **回归护栏（既有缝）**：
  - vitest 62/62：纯样式改动不应破坏任何既有测试（几何/排序/存储/日期逻辑全部不感知颜色）；
  - typecheck 零错误：碎裂模块的色值常量在 TS 内，改名触及的引用必须编译通过；
  - **构建产物静态断言**：构建后确认产物 CSS 含新色值——项目教训（2026-09-11）明确"源码存在 ≠ 产物存在"，样式验证以构建产物为准；
  - **mac dev 运行态截图**：本迭代真正的验收缝。视觉项只有眼睛能验（教训：逻辑全绿和用户看到的样子是两条验收线），逐项核对：贴纸（奶油底/橄榄墨/衬线目标/砖橙滚入）、悬浮球+速记胶囊、右键菜单、任务行 hover、归档裂纹行。
- **状态矩阵不回归**：滚入=砖橙、置顶=紫、紧急=红、叠加 红>紫>橙、裂缝红——截图覆盖。
- **先例**：阴影收敛轮的浏览器预览对照（`.scratch/shadow-polish/preview.html`）与丝滑修复轮的截图核对（`.scratch/ui-silk-restore/`）是本迭代视觉验收的同类先例。

## Out of Scope

- 真毛玻璃/blur/acrylic/vibrancy——用户明确否决（"低级的毛玻璃效果非常差劲"），任何形式不再提
- 暗色模式（后续迭代）
- 托盘图标/exe 图标资产换色（下一轮，涉及 Windows 生成脚本链）
- 版式、布局、窗口几何、交互逻辑、动画时长的任何变更
- Windows 打包装机与真机观感验证（与 blur-collapse 合并下轮）
- 打包自定义字体文件（先系统宋体，观感不佳再议）

## Further Notes

- 配色来源：用户个人网站为 JS 渲染，静态抓取无 CSS，全部色值以用户提供的截图像素实测为准（奶油 `#f0edda` / 砖橙 `#c96442` / 卡其 `#ded6b6` / 墨橄榄 `#4f5134`）。
