# Qink 第一阶段 · 设计共识（规格）

> 本文档是 2026-09-10 拷问会话（grilling）的最终共识，经用户逐题确认。
> 术语以根目录 `CONTEXT.md` 为准；重大决策见 `docs/adr/`。

## 一句话

一张常驻 Windows 桌面的纯白毛玻璃便利贴：季/月/周三层核心目标立在最上面，今日任务排在下面。写目标、加任务、勾掉任务——三个动作，仅此而已。

## 产品骨架

- **形态**：一张无边框、半透明毛玻璃贴纸，可拖到桌面任何角落；从上到下依次为季目标、月目标、周目标、今日任务。一张便利贴 = 整个产品，无标题无 Logo。
- **常驻行为**：开机自启（右键里的隐藏开关）；关闭后可从右下角托盘小图标找回；永不置顶；只在主显示器活动并记住位置。
- **哲学**：乔布斯式少即是多。高频动作零菜单零按钮；低频动作藏进右键抽屉；界面无常驻控件。

## 核心目标

- 季、月、周各**同时最多 1 条**核心目标，一句话写成。
- 目标之间互不隶属，也不管辖任何日任务——目标的作用是被天天看见，而非被分解。
- 目标区为空时显示引导文字（如「这个季度，最重要的是______」），点击即写。
- 点击已写的目标即可改写，改了即覆盖，**不保留历史**。
- 周期取自然边界：周 = 周一至周日，月 = 自然月，季 = 自然季。周期更替时该周期目标自动清空回引导文字；周期末尾写的目标也只活到周期结束（不做「写给下周期」的魔法）。

## 日任务

- **添加**：点击任务区空白处出现输入行，打字回车保存，光标留在原处可继续输入下一条，Esc 或点别处结束。
- **完成**：点击任务左侧小圆圈 → **玻璃碎裂动画**（Voronoi 不规则碎片）→ 立即从任务区消失，存入已完成清单。
- **删除/改写**：右键任务 → 极简菜单（改写 / 删除）。
- **排序**：写下的顺序就是顺序，无拖拽排序；列表超出贴纸高度时内部滚动。
- **翻篇**（自然午夜 0 点，电脑半夜关机则开机时补算）：未完成任务**滚入**次日；恰逢周期更替则对应目标同时清空。
- **滚入任务**：与今日新任务以颜色区分——**两档制**：今日新任务常规色，滚入任务统一琥珀橙（不分拖了几天）；改写任务文字不清零颜色；永不自动删除，终结只有完成或删除。
- 滚入任务排在任务区最上方，保持原相对顺序，新任务往下排。

## 已完成清单（招牌交互）

- **入口手势**：在贴纸任务区空白处**按住右键约 0.3 秒并轻轻晃动鼠标** → 已碎的玻璃碎片从各处飞回、合并成仍带裂纹的任务条，组成已完成清单，同时任务区暂时隐藏。快速点按右键仍是普通菜单（改写/删除），两种右键行为以「按住时长 + 晃动幅度阈值」区分。
- **内容**：按完成日期**永久存档**所有已完成任务，可逐日往前翻阅；只记任务，不记目标历史（见 ADR-0002）。
- **翻日**：鼠标滚轮，顶部一行淡字显示当前日期。
- **修复**：双击某条裂纹任务条 → 完全修复，从档案消失、回到今日任务区（按滚入任务显示琥珀橙，拖延年龄从创建日如实计算）。
- **只读**：不提供删除记录；确要清理直接编辑数据文件。
- **退出**：轻点任意处或 Esc，碎片反向碎开，任务区回归。

## 视觉与手感

- **毛玻璃**：纯白毛玻璃路线 = 壁纸预采样 + 整图预模糊 + 窗口位置平移同步（拖动零实时计算，丝滑由构造保证）；动态壁纸时自动退回纯半透明；抽象出可替换的玻璃层，Win11 22H2+ 自动切换官方 API（见 ADR-0003）。
- **碎裂动画**：d3-delaunay（约 6.75 KB）切 Voronoi 不规则碎片 + canvas 绘制；小区域（约 260×28 px）性能余量极大。
- **字号**：无可见控件，右键藏「小 / 中 / 大」三选。

## 右键抽屉（全部低频功能）

- 右键任务：改写 / 删除
- 右键任务区空白：长按晃动 = 已完成清单手势
- 右键贴纸空白（目标区等）：开机自启开关 / 打开数据文件夹 / 字号三选 / 退出

## 数据

- 纯本地，无账号无联网（公司电脑场景）；单个 JSON 文件存于「文档」目录，格式与框架无关（见 ADR-0001 后果）。

## 技术决策（详见 ADR）

- ADR-0001：Electron 桌面框架（本机 Node 齐备、第二阶段 MCP 生态最顺；接受 ~100 MB 体积讽刺）。
- ADR-0002：任务永久存档、目标零历史的不对称策略。
- ADR-0003：假毛玻璃渲染路线 + Win11 升级路径。

## 设计自由项（实现时我定，做出来看实物再调）

碎裂/合并动画的具体手感（时长、碎片密度、缓动曲线）、字体选型、贴纸默认尺寸、引导文字具体文案、琥珀橙的准确色值、半透明度。

## 明确不做（第一阶段）

账号/云同步、目标历史与统计图表、拖拽排序、置顶、多贴纸、多显示器、MCP（第二阶段）。

## 已知并接受的软肋

- 贴纸聚焦悬浮于其他窗口之上时，毛玻璃背后显示壁纸模糊而非真实窗口（罕见瞬间穿帮）。
- 全屏使用软件时贴纸被完全遮挡，「天天被看见」打折——第一版无解，接受。
- 拖入任务拖一周和拖一天同为琥珀橙，看不出具体拖了几天（两档制的代价）。
- 隐藏手势有发现性成本——用户即设计者，可接受。
