# ADR-0006：阴影克制、雾量自适应与文字对比度

日期：2026-09-11

## 背景

用户实测反馈三点：① 阴影光晕范围太大；② 便签盖在桌面或其他应用上时玻璃呈"怪异亮青色块"；③ 文字颜色太淡。取证：阴影来自 CSS `--note-shadow`（24px 偏移/56px 模糊/30% 浓度）；玻璃为壁纸预采样假玻璃（ADR-0003/0004），亮青色块源于 `saturate(1.5)` 提饱和叠加固定 42% 白雾对高饱和壁纸无适应；引导语/提示文字不透明度仅 0.32~0.38。本机为 Win10，无稳妥的实时玻璃方案（backgroundMaterial 仅 Win11；桌面截图 API 于 M11 两次失败 0x80004002）。用户决定玻璃机制本次不动，仅调雾量（选"中等雾量+自适应"档）。

## 决策

- **阴影克制**：主阴影 24px/56px/0.3 → 12px/28px/0.2，辅影 2px/10px/0.14 → 1px/4px/0.12。窗口透明边距（56/40/88）不变，小阴影仍被完全容纳，几何与窗口尺寸零影响。
- **雾量自适应**：白雾基线 42% → 55%；每次采样完成后把模糊贴图缩到 8×8 取平均色，纯函数 `mistAlpha`（src/shared/glass.ts）输出 0.55~0.70 写入 `--note-mist`——壁纸越高饱和/越亮/越深雾越重，中性中亮壁纸保持基线，换壁纸自动重算。
- **文字对比度**：.plabel 0.34→0.55、.goal.ghost 0.38→0.6、.composer-hint 0.32→0.55、.archive-empty 0.34→0.5、.archive-help 0.4→0.55；新增 input::placeholder 显式色 rgba(29,29,31,0.45)。

本决策替代 ADR-0004 中"42% 白雾"与大阴影的固定参数；玻璃合成路线（壁纸预采样 + 平移同步）仍遵循 ADR-0003/0004。

## 代价

高饱和壁纸下玻璃偏素偏白（saturate(1.5) 保留，观感趋向"磨砂白卡"而非"壁纸染色"）；盖在其他应用上时玻璃背后显示的仍是壁纸而非真实内容——这一本质局限保留，用户知情并搁置实时化改造。

## 验证

tests/mist.test.ts 覆盖 mistAlpha 边界（中性/亮青高饱和/深色/纯白/极端色封顶）；vitest 与 typecheck 全绿；dev 实机核对阴影收敛与亮青壁纸上的文字可读性。
