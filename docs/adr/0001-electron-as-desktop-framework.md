# 用 Electron 而非 Tauri 作为桌面框架

目标机器是公司配的 Windows 10 电脑（32 GB 内存），本机已装好 Node.js 全家桶，而 Rust 工具链和 C++ 编译器完全缺失；产品需要无边框半透明常驻小窗、系统托盘和开机自启，第二阶段还要做 MCP 连接 AI 工具。**决定用 Electron**：零环境安装、当天可开工、全程一种语言（JavaScript），且第二阶段 MCP 有官方 TypeScript SDK 生态最顺。

## Considered Options

- **Tauri**（放弃）：成品约 5-10 MB、内存约 50 MB，哲学上更配「轻如鸿毛的便利贴」，但需要在本机安装 Rust + 约 3 GB 的 MSVC Build Tools——公司电脑可能需要 IT 权限，且新手环境踩坑概率高。
- **Python 桌面方案**（放弃）：无边框窗口、托盘、毛玻璃这些细节坑多，生态不如前两者。

## Consequences

- 一个「禅意便利贴」重约 100 MB 安装包、常驻约 150 MB 内存，是有意的讽刺性取舍：产品的禅在交互与信息设计，不在字节数。
- 若未来追求轻量化迁移，数据文件格式必须保持简单、与框架无关（纯 JSON），UI 层可移植、底层需重写。
