# ADR-0004：原型一致的玻璃合成与阴影边界

日期：2026-09-11

## 背景

用户要求彻底还原外部设计原型 index.html。原来的白雾在不透明壁纸层下面，雾面被遮盖；320×540 窗口也裁掉贴纸外阴影。Win11 系统材质会覆盖透明留白，无法保证原型一致。

## 决策

贴纸固定为 320×540，窗口扩至 432×668；左56、上40、右56、下88容纳阴影。透明留白使用鼠标穿透。保存位置仍表示贴纸左上角，不改变已有数据含义。

Windows 10/11 统一走壁纸预采样路线：按原图比例铺满主屏，边缘像素延展后做26px模糊，叠加饱和/亮度，再盖42%白雾及白色内描边，文字在最上层。此决策替代 ADR-0003 的 Win11 自动升级分支。

## 代价

失去 Win11 对其他应用窗口内容的实时模糊；和此前已接受的采样路线一样，浮到其他窗口上时显示的是壁纸。桌面不同，玻璃底色自然不同；不把原型山景替换成用户系统壁纸。当前图像映射按常见的填充模式处理，特殊壁纸平铺布局仍有偏差。

## 验证

.scratch/ui-restore/verify.cjs 使用实际 Electron 构建与内存测试数据，对照原型渲染坐标、截图与交互。窗口边界由 tests/window.test.ts 覆盖。
