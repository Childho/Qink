# ADR-0008：阴影统一为四档墨色 token

日期：2026-09-27

## 背景

用户反馈阴影「太突兀、太多了」。取证：M10+ 蛋白石琉璃材质（实色哑光面、零 blur）把深度全押在分层阴影上，主阴影回弹到 24px 偏移 / 56px 模糊 / 30% 浓度的深海军蓝 `rgba(10,14,28,…)`——比 ADR-0007 曾收敛到的 12/28/0.2 更重；且五个带影表面各自为政：便签（双层+勾边+厚度线）、悬浮球（**三层**投影+勾边+厚度线）、菜单（12/32/0.22）、速记胶囊（12/32/0.18）、拖动排序行（6/18/0.18），参数互不成体系。30% 浓度大模糊在亮色桌面上形成一圈显眼的暗色光晕，蓝调色相与墨色主色也不搭。

## 决策

- **阴影只许用 `:root` 四档 token，禁止元素自定参数**，档位语义 = 离桌面高度，浓度全部 ≤ 0.2：
  - `--shadow-float` 常驻悬浮（便签 / 悬浮球）：`0 10px 28px .16` + `0 2px 6px .08`（环境影 + 接触影，接触影负责「着地」）
  - `--shadow-raised` 抬起一档（hover / 拖起）：`0 14px 32px .2` + `0 3px 8px .1`
  - `--shadow-overlay` 盖在便签上的浮层（菜单 / 速记胶囊）：`0 8px 24px .18`
  - `--shadow-inline` 卡片内部浮起（拖动排序行）：`0 2px 8px .12`
- **色相统一墨色** `rgba(29,29,31,…)`（`--fg` 同源）——影子是墨的延伸，不带蓝调。
- **层削减**：悬浮球三层投影 → 两层（float 自带接触影）；hover 与拖起共用 `--shadow-raised`，更强的抬起感由 `scale(1.07)` 承担；删除 `--note-shadow` 变量（曾经的单点配置，参数回弹正说明缺体系）。
- 环影勾边（`0 0 0 1px rim`）与底部厚度线保留——近白表面之间的分离主要靠勾边，阴影只管对桌面的深度。

否决的替代方案：单层无接触影——低浓度大模糊单独存在像雾，贴纸显得飘在半空；每表面继续微调参数——正是本次病灶（M14 收敛过一次，M10+ 材质改造时又各自回弹）。

## 代价

极亮壁纸下便签着地感略轻（接触影仅 0.08）；浮层与便签同为近白色，压叠处的分离更依赖勾边——预览实测菜单压便签角仍清晰可辨。若未来仍觉弱，只许在 token 上调，不许回到元素级参数。

## 验证

`.scratch/shadow-polish/preview.html` 复用真实 `style.css`，在 Windows hero 壁纸（饱和渐变兜底）上摆出便签/悬浮球/速记胶囊/菜单/拖动行五表面，整页与局部放大截图确认：暗色光晕消失、菜单分离度足够、球与胶囊有着地感。阴影外包络最大竖向 10+28=38px、横向 28px，均小于窗口透明边距（40/56/88），无裁切。纯 CSS 改动，测试与类型检查不受影响；渲染层 dev 热更新即时生效，安装版需重新打包。
